# CampusShield AI 2.0

## Mission
Build an evidence-driven cybersecurity platform for AI-agent
environments and campus infrastructure.

The platform will protect agents, tools, memory, data and
network activity through monitoring, detection, investigation,
and controlled, verifiable security responses.

## Member A
- Port and improve the SOCrates core engine.
- Build external AI-agent integration SDKs and APIs.
- Build detection and intelligence capabilities.
- Build live telemetry and authorized network traffic monitoring.
- Build event normalization and correlation foundations.
- Own all engineering not assigned to Members B and C.

## Member B
- Agent network and agent interactions.
- Shared memory.
- Memory infection detection and remediation.
- Counterfactual attack replay.

## Member C
- Product-level SOCrates integration.
- Privacy blast-radius analysis.
- Self-auditing.
- Adaptive least-privilege response.
- Dashboard and reports.

## Principles
- Preserve the original CampusShield idea.
- Support external agent environments.
- Support authorized real network traffic monitoring.
- Use evidence-driven detection and investigation.
- Test before declaring features complete.
- Respect module ownership between team members.
